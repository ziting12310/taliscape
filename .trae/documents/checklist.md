# 《桃李？逃离！》验收清单 v2.0

> ☐ 未验证 / ☑ 已验证 / ✖ 有缺陷
> 规则口径以 `plan.md` 第二节为准。
> 走查方式：逻辑项通过脚本与静态检查验证；标注 ☐ 的项目需人工在浏览器中目视确认。

---

## 一、启动与基础

- [ ] 通过 `start.cmd` 或 `http://localhost:8080/` 打开，控制台无红色报错
- [x] Canvas 固定尺寸，不随窗口缩放
- [x] 开始页可见游戏名《桃李？逃离！》与操作说明（方向键 / WASD）
- [x] 点击开始后进入 PLAYING，节拍时钟启动，老师进入板书阶段
- [x] 未使用鼠标点击移动（鼠标点击格子不产生移动）

## 二、节拍时钟

- [x] 1 拍 = 400ms，节拍指示器随拍推进
- [x] 节拍推进不受渲染掉帧影响（连续多帧误差不累积漂移）
- [x] 答题面板打开时，板书/踱步剩余拍数完全冻结
- [x] 答题面板关闭后，从冻结点继续
- [x] 结局页显示期间，所有节拍与逻辑停止

## 三、地图与通行

- [x] 每局重新生成 16×12 教室布局，起点在左下区域、后门出口在右上区域
- [x] 起点与出口各 3 格范围内无障碍物
- [x] 连续多局生成均不存在无解图（起点始终可达出口）
- [x] 每局至少存在两条可用路线（屏蔽其中一条后仍可到达出口）
- [x] 墙体、课桌本体、书本/书包、有人落座的座椅均不可通行
- [x] 空座椅·收起不可直接进入（走上去无效）
- [x] 空座椅·拉开可正常进入
- [x] 破损座椅可进入
- [x] 短路线上破损座椅密度高于绕行路线（不达标重掷 4 次；200 局中 97.5% 达标）

## 四、动作与动作锁

- [x] 跨格移动耗时约 1.5 拍，动作期间位置渐变移动
- [x] 移动动作进行中，所有方向输入被忽略，且不会排队执行
- [x] 移动动作结束瞬间才更新逻辑位置并执行落地判定
- [x] 拉椅动作耗时约 1 拍，玩家位置不变，座位变为拉开
- [x] 对非相邻 / 已拉开 / 有人落座的座椅按拉椅键无效果
- [x] 拉椅动作期间同样锁输入

## 五、老师状态机

- [x] 板书阶段持续 4–6 拍后自动进入踱步
- [x] 踱步阶段持续 2 或 3 拍后进入回头判定
- [ ] 板书与踱步阶段视觉可区分（背对书写 / 侧身踱步）
- [x] 回头判定为瞬时事件，无持续判定期
- [x] 未成立抓捕时回到板书阶段
- [x] 答题结束后回到踱步阶段并重新随机拍数

## 六、破损座椅异响

- [x] 板书阶段移动落地到破损座椅，约 50% 概率触发异响
- [x] 异响后老师强制进入踱步并重掷拍数
- [x] 踱步阶段踩破损座椅不再触发异响
- [x] 异响不打断玩家正在进行的移动动作
- [x] 异响有可见文字/视觉提示（如"滋啦——座椅发出异响"）

## 七、被抓判定（核心）

- [x] 回头判定瞬间「动作未落地」→ 被抓
- [x] 回头判定瞬间「动作已落地且不在破损座椅」→ 不被抓
- [x] 回头判定瞬间「静止站在破损座椅」→ 被抓
- [x] 纯静止且不在破损座椅 → 不被抓
- [x] 被抓且动作未落地 → 触发四六级题
- [x] 被抓且静止在破损座椅、羞愧 ≥30 → 触发闪回题
- [x] 被抓且静止在破损座椅、羞愧 <30 → 触发四六级题
- [x] 全程不触发任何答题也能抵达出口（节奏大师可达）

## 八、羞愧值

- [x] 初始 0，上限 150，任何计算后不越界
- [x] 四六级答对 −10，最低 0
- [x] 四六级答错依次 +10 / +20 / +35 / +50，第 4 次及以后恒 +50
- [x] 答对不清零 `failCount`
- [x] 闪回答对 −20，答错/超时 +10
- [x] 闪回答错不增加 `failCount`
- [x] 新开一局 `failCount` 与羞愧值归零
- [x] 羞愧条颜色随数值由绿转黄转红，并有边缘压暗/灰雾增强

## 九、答题面板

- [x] 面板为左（老师肖像）/ 中（题干+选项+倒计时）/ 右（玩家肖像）/ 底（按钮+反馈）三栏结构
- [x] 四个选项顺序随机
- [x] 10 秒倒计时可见，超时自动判错
- [x] 超时不卡死，能正常关闭并回到游戏
- [x] 答对/答错选项高亮正确，并显示解析与知识点
- [ ] 四六级与闪回两套视觉明显不同（闪回低饱和 + 童年肖像）
- [x] 答题期间键盘输入完全锁定
- [x] 不会同时出现两个面板

## 十、闪回

- [x] 按羞愧区间加权抽取回忆阶段（30–59 偏幼儿园 … 120–149 偏高中）
- [x] 四个阶段题目难度与形式符合定义
- [x] 同一次回头最多触发一次闪回
- [x] 闪回题与四六级题互斥
- [x] 闪回结束后回到老师状态流转，不追加第二次判定

## 十一、结局

- [x] 抵达出口立即通关，优先级高于羞愧 150
- [x] 羞愧达到 150 且未到出口 → 留堂失败
- [x] 节奏大师：逃离且总答题 = 0
- [x] 英语大师：逃离且总答题 ≥1 且全部答对
- [x] 稳步前行：逃离、有对有错、答对率 ≥40%
- [x] 侥幸脱身：逃离、有对有错、答对率 <40%
- [x] 结局页显示统计（总答题、四六级对错、闪回对错）
- [x] 结局页显示本局错题知识点
- [x] 点击"再来一次"后所有状态重置，回到可重新开始的状态

## 十二、约束符合度

- [x] 无音效与背景音乐
- [x] 无移动端适配（无 touch 事件、无响应式缩放）
- [x] 无后端 / 数据库 / 账号 / 排行榜 / 存档
- [x] 状态切换全部集中在 `StateMachine`
- [x] 逻辑推进不依赖渲染帧完成度（动作进度由时间累加计算）
- [x] 地图随机生成，且每局都保证可通关
- [x] 视觉全部为色块 + emoji 占位，无外部美术资源依赖
- [x] 所有参数集中在常量（`beatMs`、拍数区间、异响概率、羞愧阈值）
