
# Taliscape
中文名称：**桃李·逃离！**
命名由来：TaoLi（桃李，指代学子） + Escape（逃离）

一款聚焦大学生四六级备考焦虑的节拍潜行功能游戏。

## 🎮 游戏介绍
教室是焦虑的隐喻空间。玩家跟随节拍移动，躲避老师的注意：
- 普通抓捕：回答四六级真题
- 羞愧值≥30时被抓捕：触发记忆闪回，面对早年的挫败习题
- 羞愧值累积至150：心态崩盘，留堂失败
- 成功抵达后门：解锁对应结局，弹出错题复盘面板

## ✨ 设计立意
我们逃离的从来不是课堂，而是考试带来的沉重压力。
即便短暂躲开压力，知识漏洞依旧需要正视。
希望玩家在紧张的博弈中觉察自身焦虑，以更低抵触感完成英语练习。
